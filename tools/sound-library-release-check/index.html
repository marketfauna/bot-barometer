1. Bring your metadata

Use an existing UTF-8 CSV or TSV export. Every column and record is retained as text. This tool does not extract or embed audio metadata. Your input needs named columns and actual filenames, including their extensions. Other spreadsheet formats need a deliberate CSV/TSV export first.

2. Choose the final file set

Include the audio files the metadata should describe. All selected entries are checked; nothing is silently filtered by extension.

Use / separators. Spaces, case and Unicode are preserved. Absolute paths, blank entries and . or .. segments are held for review.

Paths start inside the selected folder; its outer folder name is excluded. Subfolder names remain intact. The browser reads filenames, not audio contents.

Ordinary file selection exposes basenames only. Select a folder or paste paths to retain subfolder identities.

Case and Unicode variants are reported, never silently joined. Basename mode holds names shared by multiple files.

These are filename and supplied-data checks. They do not assess embedded metadata, descriptions, audio quality, licensing, UCS correctness or ZIP contents.

Download review documents

Both documents include unresolved records and review status. All original fields are retained, including private notes or paths: inspect them before sharing. PDF shows each field per record; tabs are displayed as \t.

Names use letters, numbers, hyphens and underscores; spaces become underscores. Naming conventions come from the A Sound Effect vendor guide. These review documents are only part of a release package.
